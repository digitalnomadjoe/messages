## Why this is differentiation and not the base-gait shift again

The row-119 audit's decisive fingerprint was that the confounded run moved every cell by the same
amount. This run does not:

| c_cmd | pre-repair CY | **probe (294,912)** | Δ | confounded 884k Δ (884,736 steps) |
|---|---|---|---|---|
| 0.70 | 1.9122 | 1.8672 | **−0.0449** | +0.0653 |
| 0.85 | 1.6105 | 1.5929 | **−0.0177** | +0.0585 |
| 1.00 | 1.0901 | 1.0855 | **−0.0046** | +0.0729 |
| | | **spread of Δ** | **0.0403** | 0.0144 |

The probe's change is **concentrated at the low-cadence end and decays monotonically to almost
nothing at c = 1.00** — precisely the shape that flattens an inverted slope. The confounded run's
change was uniform (spread 0.0144, all three the same sign and size), which is why its slope barely
moved despite every cell moving ~2.5× further.

**Matched-budget control.** At the *same* 294,912-step point the confounded run had ep_len 63.1 /
ret 3.32 / EV 0.382; this probe has **ep_len 61.8 / ret 3.19 / EV 0.395** — statistically the same
walking quality. So the slope difference is **not** bought by better walking, which is exactly the
confound the ticket told me not to be fooled by. The probe reaches **+0.1343** at one-third the
budget the confounded run spent to reach **+0.0255**.
