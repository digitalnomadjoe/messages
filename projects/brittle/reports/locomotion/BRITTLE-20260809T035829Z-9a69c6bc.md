## 1. The term

Ten edit sites, all additive. The state machine is `ReftrackAdapter._cadence_step`, a
vectorized transcription of row 112. Two implementation choices worth stating:

* **`cad_since` + `cad_has` instead of an absolute `td_last`.** They are exactly the licensed
  `(t − td_last)` / `(td_last ≥ 0)` pair. I avoided an absolute step index deliberately:
  `self.tick` is reset under `dm_z`, a **different mask** from the reward reset `dm` (ET-injected
  rows keep their frame), so a tick-based interval could span a reset on exactly those rows.
* **`cad_prev` initialises and resets to `True`**, so a foot already in contact at spawn is not
  read as a touchdown.

**Disabled means disabled:** the call site is `if self.cadence_track_w > 0.0: … else: zeros`.
A fully skipped branch — not `0.0 * term`, which would also propagate a NaN.

## 5. Degenerate and adversarial — 7/7

standing → **−0.46875 (the cap)**; one-foot hold → **−0.46875**; chatter → −0.20692;
missed touchdown penalised (−0.02930 vs 0.00000 clean); **no double-counted rising edges** —
closed intervals equal true rising edges minus one per foot, and a 1-step contact dropout adds
exactly one edge and exactly one interval; **no reward spike at reset** (max step-to-step change
across the reset = 0.00000, because `p_cadence[dm] = 0.0` joins the existing term-zeroing line);
no stale rho between worlds.

### Mid-episode command change — defined, not left ambiguous

**An interval is scored against the command in force when it CLOSES.** `_cadence_step` reads
`self.cadence_cmd` at the closing step; no per-foot snapshot of `T_cmd` is stored. Rationale: the
penalty is compared every step against what the operator is asking for *now*, and scoring a
closing interval against a *withdrawn* command would reward tracking a command no longer in force.

Verified: with a 1.0 s gait, penalty −0.000000 while `c_cmd = 1.00`, and **−0.021875** once
`c_cmd` changes to 0.70 mid-episode with the gait unchanged.

**Today this path is a no-op** — `cadence_cmd` is set per world at reset from its member and is
constant within an episode. It is defined and tested now so that adding command scheduling later
cannot silently change the semantics.
