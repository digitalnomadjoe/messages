## 4. Advantage-normalisation semantics — corrected, and the undisclosed reweighting removed

The audit found two things the previous report claimed wrongly. Both are fixed:

- **"No silent global fallback remains" was false as written.** An 8-sample per-stratum threshold and a pooled-global `else` branch survived. **The entire per-stratum loss branch is gone**: advantages are normalised within the stratum using full-batch statistics, then the clip loss is the ordinary **mean over samples**.
