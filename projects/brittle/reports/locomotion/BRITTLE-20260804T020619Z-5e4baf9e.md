## 1. Latch initialization audit — FAIL, measured

Reset capture (live buffers): `last_real_td_foot = −1`, **`alt_state = 1` — the latch is born ARMED**. Consequences, all measured on the live kernel (64 worlds each):

| adversary | result |
|---|---|
| static one-legged single support (C11S4I-style injection at reference SS frames, zero action, zero velocity) | **PRE-ALTERNATION income: r_single_support +0.0244 and r_ss_hold +0.0157 cumulative per world** over ~60-step first-episode windows — a flamingo with ZERO touchdowns ever earns SS economy |
| one-foot balancing, no touchdowns | same probe: income accrues from step 1 (alt_state=1 at birth) |
| repeated same-foot hopping | first event pays, then latch closes (C11S8 result; unchanged) |
| one valid touchdown → prolonged single support | pays the td (airtime+cadence) AND continues SS accrual until a same-foot repeat breaks the latch |
| proper L-R alternation (s2-final) | first QUALIFIED td med step 48; first ALTERNATING td med step 64; **airtime+cadence pay at 48 (before alternation, 64/64 worlds); ss_hold pays at step 13** (spawn-stance SS-exit); single_support at 47 (58/64 pre-alternation) |

The ticket's requirement — no gait-cycle or single-support income before a valid alternating PAIR — is violated by initialization, not by the release logic.

**Minimum initialization/arming correction (returned, NOT implemented):**
1. reset `alt_state = 0` (unarmed) — one value in the reset kernel + the buffer init;
2. release/arming predicate `(last_real_td_foot >= 0) and (last_real_td_foot != i)` — the FIRST qualified touchdown only sets the register; the SECOND, alternating touchdown arms the latch and is the first paid event (airtime/cadence release switches to this predicate; single_support/ss_hold already gate on `alt_state`).
Cost to genuine walking: one unpaid first step + unpaid spawn stance (~0.6 s ≈ 0.5% of episode income); arc-RSI spawns unarmed for ~0.6 s. Hop/flamingo/slide/chatter income becomes exactly 0 at all times.
