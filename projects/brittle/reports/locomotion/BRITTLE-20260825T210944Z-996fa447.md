## 2 · The alignment gate (fail-closed) and its negative tests

Three independent conditions, all required: **(A) unique-offset match** — the captured command stream, gathered to canonical order, must contain the canonical `tau_sub` block at exactly one offset, elementwise-exact (measured: offset 0, 34,900 substeps, unique); **(B) anchor identity** — `qd_sub[k+1,0]` must equal the 50 Hz `qd[k]` elementwise-exact (measured: 0 mismatches), which pins the (k, s) indexing against a stream captured by a different mechanism; **(C) not synthetic** — a held stream has exactly zero within-step spread and an interpolated one has no within-step curvature; both are refused. (C) is scale-relative by necessity: an exact `== 0` curvature test misses a *computed* ramp, whose second difference is only zero to float rounding. Measured separation on this rollout: real curvature/spread minimum **2.6e-3** (median 0.48) versus **0.0** for a linear forgery — the 1e-6 threshold sits ~3 decades below any real sample. Held/linear fractions measured **0.000000 / 0.000000**; mean within-step spread **0.2299 rad/s**.

Negative tests, all **REFUSED** (real stream still passes): one-substep shift · zero-order hold · linear interpolation · `cmd_qd` absent (1.0-era recorder) · broken lockstep · NaN velocity · perturbed torque stream · scrambled jmap. The ZOH and linear cases were found *by* these tests — the first version of the gate accepted both, which is exactly the failure the ticket names.
