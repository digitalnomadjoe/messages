## 5. ⚠ What did improve, and it matters for the architecture call

**Mean speed error fell monotonically at every checkpoint: 0.0245 → 0.0228 → 0.0215 → 0.0203**,
and max speed error with it (0.0527 → 0.0407). **0.0203 is the best speed error measured anywhere
in this arc** — better than row 133's legacy best (0.0222) and essentially at the ±0.020 band that
has blocked this lane since row 129.

So the picture is not "nothing worked". It is:

- **the policy is getting steadily closer to commanded speeds** (error down 17 %, monotone), while
- **its responsiveness to the cadence command peaked and reversed**, and
- **its responsiveness to the speed command barely moved** (slope +0.0248, 1.8× noise, non-monotone).

Errors shrinking while *slopes* stall is the signature of a policy converging onto the middle of
the command distribution rather than learning to span it. That is the same shape rows 125/126
described, now surviving a correct phase clock.

## 6. Recommendation

**STOP.** The phase-state plumbing is correct — probe K verified the clock advances at exactly
`c_cmd`, including at an untrained cadence — and continuation L shows that **fixing the clock was
necessary but is not sufficient.** Giving the policy a correct per-stride timing reference bought
a real but bounded cadence gain that then reversed under further training.

For the capacity/architecture consideration, three things from this run:

1. **The best checkpoint is not the last.** `L +589,824` / `15df7d8921b9e110` holds the arc's best
   surface cadence slope (−1.6339). If anything is carried forward, carry that.
2. **The reversal is the finding.** It is 4.3× the noise floor and it happened while survival,
   curvature and speed error were all still improving — so it is not a collapse, it is the cadence
   axis specifically giving ground while everything else advances. That argues the constraint is
   representational capacity for command differentiation, not stability or optimisation health.
3. **⚠ Watch the measurement, not just the model.** Span is unmeasurable at ±5 points and the
   3-cell gate has been unusable since probe K. Any next design should state up front which
   quantities it can actually resolve; on current instruments that is cadence slope (±0.023),
   speed slope (±0.014) and speed error — not span.
