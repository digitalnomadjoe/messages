## 1. The exact-policy contract and its identity

**P29 `--exact-symmetry`** (opt-in, default off) installs `g(o) = ½[f(o) + M_act f(M_obs o)]` as `actor_mean` on the policy instance. Because `act() → dist() → self.actor_mean`, and Python resolves instance attributes before methods, **every downstream call site inherits g**: rollout sampling, old and new log-probabilities, the PPO ratio, entropy bookkeeping, the anchor target and every auxiliary head. Gradients flow through both evaluations of the same parameter set; the mirror maps are fixed constants; there remains exactly one trainable actor. **`--mirror-reg-w` stayed at 0.0** — the soft penalty was not used as a substitute, as the ticket requires.

**Candidate identity** — the actor is not the weights alone:

| component | hash |
|---|---|
| base weights (Q8 student) | **`86e69e84da50cab9`** |
| obs mirror `P29_Mobs.npy` | **`9c564de2c4568d98`** |
| action mirror `P29_Mact.npy` | **`23289b73d9b23faa`** |
| trainer carrying the symmetrized forward | **`5c94b9fa00457345`** |
| launcher | **`7d5b03a68d12779d`** |
| final checkpoint (underlying f) | **`f86587973fab992e`** |

Pre-optimization proofs: involutions exact, action mirror re-derived and asserted against `JOINT_NAMES`, and **in-trainer functional equivariance residual 0.000e+00** before the first gradient step (the trainer hard-fails above 1e-5). The negated obs dims are exactly {0, 4, 5, 6, 45} — gravity-X, angular-velocity Y and Z, linear-velocity X, and the command — matching the documented convention.

★★★ **A defect found by cross-validation, and the reason the matrices are loaded rather than rebuilt.** My first implementation built the mirror from the in-tree `MirrorReg`. Cross-checking it against the P-validated operator showed **`MirrorReg.mirror_obs` disagrees on obs dims 3 and 4 by exactly 2.0** — opposite signs on body angular velocity. For a mirror whose normal is body-X a pseudovector must preserve X and negate Y and Z, which is what the P operator does. **`MirrorReg` has only ever run at `--mirror-reg-w 0`, so this path was never exercised in any prior unit.** Had I used it, the actor would have been made equivariant with respect to the *wrong* transform and the whole run would have been corrupted. The trainer now **loads** the matrices from the validated operator and refuses to start without them. **I am reporting this as a defect in a shared component; I have not modified `MirrorReg`, which is outside this ticket's scope and needs its own adjudication.**

- `EXACT-SYMMETRY PPO CANNOT INCREASE TURN MAGNITUDE` — **false, and this is the unit's positive result**: both magnitudes rose, together, deterministically past 1.0 and stochastically by +0.013/−0.008 at 32×5.
- `STRAIGHT OR ROBUSTNESS REGRESSED` — false; straight improved and falls halved.
- `MULTIPLE BLOCKERS` — no refusal, no missing authorization.
- **`EXACT-SYMMETRY PPO IMPROVES BUT MISSES QUALIFICATION`** — improvement is real, symmetric and monotone in the right direction; the ±1.0 stochastic bar is not reached.

**Recommendation.** The arc has now eliminated every structural explanation — dead command exposure, advantage asymmetry, gradient interference, plant/reference/command-pathway asymmetry, left/right divergence — and the exact-symmetry contract converts what used to be a *trade* into a *joint climb*. What remains is a **symmetric ~3–5 % stochastic magnitude shortfall that is closing slowly**: +0.9550 → +0.9680 over 2 M steps. The two options I can distinguish are (i) **more of the same** — the curve is still rising at the ceiling and a longer bounded budget is the cheapest test of whether it simply needs steps, which requires raising the per-stage ceiling and is Joe's call; or (ii) **accept the measured achievable band** and re-cut the stochastic gate, since deterministic curvature clears 1.0 comfortably on both sides, symmetry is exact, falls are the lowest recorded, and torque and clearance are in contract. ⚠ Note that (i) must also address the torque-burst regression against Q2, which is the one gate moving the wrong way. **Nothing is banked, promoted or pointed at.**
