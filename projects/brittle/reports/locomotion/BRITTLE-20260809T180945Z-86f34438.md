# 12U-C11S15CY — Cadence Policy-Gradient Interference Audit: **`CADENCE REPRESENTATION ENTANGLEMENT`**

**date:** 2026-08-10 · **unit:** 12U-C11S15CY · **lane:** locomotion
**constitution:** C1, C3, C7, C12 · **potential violations:** none · **amendment proposed:** no
**prohibitions honoured:** NO PPO · **ZERO optimizer steps** · NO reward/reference/sampling/architecture/obs/action mutation · base is probe C, not failed D or E · bound trainer byte-identical throughout
**changelog:** row 125 · post-append csv `sha256_16` **`0d67b8c826900d3d`**

> **The cadence gradient is not missing, not overwhelmed, and not cancelled — it has nowhere
> distinct to go.** Even the *isolated* cadence-term gradient, with imitation and speed removed
> entirely, spends **94–96 % of its effect on command-independent base gait** and only
> **3.4–4.4 %** on the obs53 response. And the obs53 and obs52 responses are **0.903 collinear**
> before any gradient is applied.

---

## Decision

# `CADENCE REPRESENTATION ENTANGLEMENT`

**The smallest repair — enable the actor pathway that already exists:**

> Turn on **`--timing-latent`**. It is a zero-initialised FiLM modulation of the phase channels
> (obs50/51 = sin φ, cos φ) driven by **obs[52:54] = (vx_cmd, cadence_cmd)** —
> `train_tip_gpu.py:196-206`. It gives the cadence command a **multiplicative parameter subspace
> of its own** onto the phase representation, instead of entering only as one of 54 shared MLP
> inputs. The trainer already zero-inits it on load
> (`train_tip_reftrack.py:4995-5003`), so a run started from probe C is **bit-identical at step 0**.

**Why this one and not more weight, more steps, or more sampling:** items 1–3 rule out the
alternatives empirically. The measured defect is that no available parameter direction changes
cadence conditioning without moving base gait; `--timing-latent` is the smallest change that
creates one, and it is already implemented, already zero-init, and already inside the actor.

**Confidence: HIGH on the diagnosis, MEDIUM on the repair.** The diagnosis rests on a directional
derivative measured on the real policy — it is not an inference. The repair creates the missing
subspace but does not guarantee PPO will use it; that is a training question this audit cannot
settle.

---

## Method — fidelity first

Every gradient was produced **in-process by the trainer itself**, on a real live batch of
**147,456 samples**, using its own log-probs, its own GAE advantages, its own full-batch
advantage normalisation and its own clip constant (0.2). `max|ratio − 1| = 1.55e-05`, so the
clipped surrogate is at its unclipped branch — the gradient is the real PPO objective, not a
hand-built proxy.

**The bound trainer was never modified.** The capture ran on a *copy*
(`train_tip_reftrack_gradaudit.py`) that differs from the pinned `3d1cee11220a6a93` by
**18 added lines, 0 removed**, all inside the existing `--grad-audit-out` branch, which returns
before the optimizer. No checkpoint was written by any run in this audit.

Triplet strata isolated by `obs52 = 0.153` ∧ `obs45 = 0` ∧ `obs53 = c/2`, then equalised to
**6,656 samples each**.

**And it is genuinely command-distinct at the component level:**

Imitation mildly opposes cadence at the higher commands, but at −0.18…−0.41 it is friction, not
domination.

|---|---|---|
| A native | 13.6 % | **+0.01203** |

`cos(ḡ_triplet, ḡ_rest) = +0.5722`.

**Probe E's weighting does not rotate the aggregate gradient toward the observed outcome — it is
very slightly *less* aligned than native weighting.** The re-weighting hypothesis is
**disconfirmed at first order**: whatever produced probe E's long-stride regression, it is not a
gradient rotation the sampling change caused on this batch.

## 4. Command representation — the decisive measurement

Take a small step along each gradient's descent direction on the **real policy**, then measure
what actually changed at 4,096 held states: the base action, the obs53 response
(`a|c=1.00 − a|c=0.70`), and the obs52 response.

**Baseline, before any step: `cos(obs53-response, obs52-response) = +0.9030`.**

| gradient | base gait | obs53 response | obs52 response |
|---|---|---|---|
| c = 0.70 | **95.1 %** | 3.9 % | 1.0 % |
| c = 0.85 | **95.1 %** | 3.8 % | 1.1 % |
| c = 1.00 | **95.2 %** | 3.7 % | 1.1 % |
| aggregate | **95.7 %** | 3.4 % | 0.9 % |
| **p_cadence only, c = 0.70** | **95.6 %** | 3.4 % | 0.9 % |
| **p_cadence only, c = 0.85** | **95.1 %** | 3.8 % | 1.2 % |
| **p_cadence only, c = 1.00** | **94.4 %** | **4.4 %** | 1.2 % |

**This is the finding.** Strip away imitation and speed entirely, isolate the cadence term's own
gradient at a single command — and it *still* spends 94–96 % of its effect on command-independent
base gait. The best case anywhere in the table is **4.4 %** into the obs53 response.

The command-distinct demand from §2 is real, but the actor has **no parameter direction that
expresses it**: the only way it can move is through parameters that change the gait for every
command at once. And the sliver that does reach command response lands on an axis already 0.903
collinear with speed.

## Why not the other verdicts

**Not `CADENCE IMITATION-GRADIENT DOMINANCE`** — the cadence gradient is 53–66 % of the stratum
norm and at c=0.70 exceeds `track_jnt`; imitation opposes it only mildly (−0.18…−0.41). Decisive:
**removing imitation entirely does not help.** The isolated `p_cadence` gradients still push
94–96 % into base gait. If imitation were the obstacle, deleting it would free a distinct cadence
direction — it does not.

**Not `CADENCE GRADIENT CANCELLATION`** — the full per-stratum gradients are +0.50…+0.61 mutually
aligned and +0.80…+0.89 aligned with the aggregate, so minibatch aggregation preserves them. The
`p_cadence` sub-gradients *are* near-orthogonal across commands, but they account for ~4 % of the
actionable direction, and §3 shows re-weighting the strata changes the outcome not at all
(+0.01203 → +0.01151). Cancellation is not the binding constraint.

**`CADENCE REPRESENTATION ENTANGLEMENT` is the only verdict consistent with all four items** —
and it is the one item 4 measures directly rather than infers.
