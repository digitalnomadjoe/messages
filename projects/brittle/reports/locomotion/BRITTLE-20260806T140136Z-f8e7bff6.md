## 1. Root cause — one defect behind both blockers

`kappa_sign_consistency`, a per-window sign vote, gated classification; `realized_signed_curvature`, a per-window median, reported magnitude. Both are computed on heading increments between short smoothed-path windows, and both fail in opposite directions:

- **On strong turns the vote degrades as the turn gets tighter.** Two O4 worlds each swept ~155° of path heading over 2.3 m. The one on the *tighter* circle (κ_med 1.72) scored consistency **0.710** and was rejected → STRAIGHT; the looser one (0.97) scored **0.774** and passed. Tighter turn ⇒ shorter window chords ⇒ residual sway flips more window signs.
- **On near-straight paths the median fabricates curvature.** O4's three "high-curvature" straight worlds read κ_med **−0.607 / −0.619 / −0.616** with sign consistency ≈ **0.50–0.56** — a coin flip — while their **net path heading moved only −10.5° / −8.1° / −9.1° over 3.19 m** (κ_net −0.058 / −0.045 / −0.050). They walked straight.

## 2. Oracle repair — **tor-v1.7.0**, sha `c5cb35c05e62628f`

Added a **net-heading basis**: a segment qualifies as a turn on *sustained measured path curvature* — net path heading change per unit translation — using the existing floors (|κ| ≥ 0.8 over ≥ 0.60 m), guarded exactly like the segment-median basis (skipped when a window run already covers the segment), so composite and FIGURE_EIGHT semantics are untouched (a path that turns both ways has a cancelling net and cannot qualify). Added `realized_kappa_net` and `realized_radius_net_m` as **independent** robust fields; the legacy `realized_signed_curvature` is retained unchanged for continuity. Classification behaviour is otherwise identical, and only the instrument was touched — no policy, plant, law or contract change.

**Regression 21/21 PASS.** All 16 tor-v1.6.0 cases preserved. Five fixtures added: two **positive** (O4 turn w2 κ 1.72 and O3 M3 turn w0 κ 1.26 — both rejected by v1.6, both now TURNING_LEFT) and three **negative** (O4 straight det/stoch sway-alias worlds and a parent straight world — all must stay STRAIGHT, guarding the new basis against exactly the aliasing that motivated it).
