## 1. The gate was measuring the wrong function

### 1.1 The mechanism

`isaac_spectator.main()` sets a **module global** from the parsed args:

```
1235    args = ap.parse_args()
1236    _EXACT_SYM_DIR = args.exact_symmetry_matrices
```

`_install_exact_symmetry` is called at `:332` and `:714`, both guarded by `if _EXACT_SYM_DIR:`.
Every headless harness in this unit captured the namespace by monkeypatching
`ArgumentParser.parse_args` and raising `SystemExit` **inside** it — so line 1235 never
returned, line 1236 never ran, the global stayed `None`, and the wrap was never installed.

Confirmed against the logs before touching anything: `grep -c "EXACT-SYMMETRY"` returns **0**
on the headless logs and **2** on the real viewer run.

The repair is to reproduce `main()`'s own assignment after capture, then **refuse** if the wrap
is not actually bound — the gate does not assume the global took:

```python
SP._EXACT_SYM_DIR = box["ns"].exact_symmetry_matrices
...
if "_sym_predict" not in repr(st.model.policy._predict):
    raise SystemExit("BLOCKER_bare_f: ...")
```
